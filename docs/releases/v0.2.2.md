Major performance, reliability, and decoding quality release of inky cutting warm 32-lane Metal command-buffer decode dispatches **12x (`10,186 -> 843` per token)** (`1,131 -> 843` within the 3D-batched `count_step` model), eliminating steady-state CPU block-table rewrites, deduplicating cold turn-1 shared-prefix stampedes via singleflight checkpoint rebind, reducing pool-exhaustion errors on 64 GB machines through in-flight block reservation and NVMe `SpillStore` cache restore, and adding softcap-exact **Adaptive `LoopCD-Logits` (`--loopcd`)** for Inkling 2 Mini.

## What changed

### 12x fewer multi-lane Metal decode dispatches & barrier fusion

- **Shared `BlockedSlab` and 3D-batched decode kernels (`src/engine.rs`, `src/kernels.metal`, `src/prefill.metal`, `tests/golden-m5-*.txt`).** Blocked lanes sub-allocate recurrent convolution states (`cs`) and 64-bit GPU block tables (`bt_full`, `bt_win`) from a shared 256-byte-aligned `BlockedSlab` with `Drop`-driven free-list recycling, enabling single-dispatch multi-lane `k_embed_dec`, `k_attn_blk_dec`, `k_attn_combine_dec`, and fused `k_postconv_state_dec`. `k_attn`, `k_attn_blk`, and `k_attn_blk_dec` compile under `#pragma clang fp contract(off) reassociate(off)` so Layer 2 contiguous decode and Layer 3 3D-batched paged decode share exact IEEE-754 floating-point association with each other; lines 1–5 of `tests/golden-m5-*.txt` (raw logit hashes) were rebaselined from `v0.2.1`'s contracted FMA hashes while lines 6–10 (`binv`, greedy/sampled/chat token-output hashes, and `lanes`) stayed identical.
- **Direct fp16 epilogues & fused MoE top-k routing (`src/engine.rs`, `src/kernels.metal`, `src/prefill.metal`).** `k_attn_combine_dec` writes `half` directly to `b.agh` (`-48` dispatches, `-48` barriers), `ctrl_b` `down` `gemm_h` writes `hout = 1` directly to `b.gh[c]` (`-96` dispatches, `-48` barriers across decode & prefill), guaranteed-empty MoE tile class 0 (`65..128` tokens) is skipped for `n <= 64` (`-96` indirect dispatches), and `k_moe_topk_route3` fuses `k_topk_b` + `k_moe_route3` into a single threadgroup (`-48` dispatches, `-48` barriers). Within the 3D-batched `count_step` model (`src/engine.rs`), these four fusions cut **`288` dispatches (`1,131 -> 843`) and `144` barriers (`963 -> 819`)**; combined with replacing `v0.2.1`'s per-lane loops, encoded Metal command-buffer dispatches measured on a warm 32-lane decode step on M5 Pro drop from **`10,186` (`v0.2.1`) to `843` (`v0.2.2`)** per token, and `encode_gumbel_spans` batches multi-lane Gumbel sampling into `1` encoder (`2` barriers instead of `32` encoders / `96` barriers).
- **Dirty-range incremental `sync_lane_block_table` (`src/blocks.rs`, `src/engine.rs`).** `BlockTable` tracks per-kind `[dirty_lo, dirty_hi]` bounds, writing `0` bytes on the `63 / 64` steady-state decode steps where no block changed.

### Turn-1 singleflight prefix deduplication, bounded decode reservation, and SSD spill

- **Cold-stampede singleflight prefix rebind (`src/serve/block_cache.rs`, `src/serve.rs`).** Concurrent requests sharing an uncached prefix (`>= 2048` tokens, such as `opencode` or `claude` system+tools prompts at sprint startup) elect an acyclic `(n_past, -lane)` leader to prefill and seal periodic `EVERY` checkpoints once while followers hold without accruing bypass ticks and immediately rebind via `ServeBlockCache::rebind_if_deeper_match`.
- **Bounded in-flight pool reservation, graceful step deferral, and `SpillStore` integration (`src/serve/block_cache.rs`, `src/serve.rs`, `src/spill.rs`).** `can_admit_with_shared` subtracts active lanes' remaining unwritten prompt + decode-reserve `Full` blocks, `ensure_span_blocks` rolls back transactionally and defers transiently contended lanes instead of failing with HTTP `500`, `cb.commit()` overlaps host queue/cancellation work during GPU execution, and `--spill-dir` spills LRU-evicted `RetainedStart` checkpoints to NVMe SSD with SHA-256 verified restore on `match_and_bind`. Decode reservations are capped at 4,096 tokens. When every runnable lane is waiting for capacity, the scheduler can fail one request to release its blocks.

### Softcap-exact Adaptive `LoopCD-Logits` (`--loopcd`)

- **Training-free recurrent contrastive decoding (`src/engine.rs`, `src/kernels.metal`, `src/main.rs`, `src/serve.rs`).** Implements Adaptive `LoopCD-Logits` (`--loopcd <omega_max>`, Liu et al. 2026, arXiv:2610.02185) for Inkling 2 Mini's prelude–loop–coda stack: runs a dry-state (`no_state_write`) coda + `lm_head` pass after recurrent pass `1` without touching cached K/V or `cs`, applies logit softcapping (`c * tanh(z / c)`) to both $z_3$ and $z_1$, scales $\omega_t = \omega_{\max}[1 - (p_{3,(1)} - p_{3,(2)})]$ by top-2 margin uncertainty in `k_loopcd_blend`, and bypasses double-softcapping downstream.

## Getting started

With Rust installed, `cargo install inky-engine` builds and installs `inky` from crates.io instead.

The model is LM Studio's `Inkling-2-Mini-Q4_K_M.gguf` (or a `native-q8rest-o6` GGUF converted with `tools/inkconvert`), read by default from `~/.lmstudio/models/lmstudio-community/Inkling-2-Mini-GGUF/`; `-m` points at another path.

```sh
gh release download v0.2.2 -R robotgamedevelopers/inky
shasum -a 256 -c SHA256SUMS
mv inky_v0.2.2_darwin_arm64 inky && chmod +x inky
./inky chat
```

To serve over loopback or a private network:

```sh
sudo ./inky tune-memory                                # once, optional: installs inky mode
./inky serve --lanes 32 -c 131072 -n 16384             # standard decoding
./inky serve --lanes 32 -c 131072 -n 16384 --loopcd 0.3 # with Adaptive LoopCD-Logits
```

[docs/README.md](https://github.com/robotgamedevelopers/inky/blob/v0.2.2/docs/README.md) and [docs/FLEET-SPRINT.md](https://github.com/robotgamedevelopers/inky/blob/v0.2.2/docs/FLEET-SPRINT.md) cover every command, serve flag, and fleet provider recipe.
