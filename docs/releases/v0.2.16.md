Inky 0.2.16 enables 8-bit quantized KV caching (`--kv8`) by default in `scripts/inky-fleet-serve.sh` (`INKY_KV8=1`, `INKY_KV8=0` for exact FP16) following single-tenant Apple M5 Max (128 GB) `20K`-context scaling benchmarks against `llama.cpp`, `21K–24K`-token exact-needle and `go test -race` quality verification, and a `1,242`-turn production fleet replay across `8..96` concurrent 64K lanes.

- `scripts/inky-fleet-serve.sh` adds `INKY_KV8=${INKY_KV8:-1}` (passing `--kv8` by default, omitting `--kv8` when `INKY_KV8=0`, and failing with exit code `2` on invalid values), covered by `tests/fleet_serve_script.rs`. Raw `inky` CLI commands retain exact FP16 KV caching unless `--kv8` is explicitly supplied.
- Single-tenant warmed `20K`-context (`~20,480` tokens per lane/slot, zero cross-slot KV sharing) benchmarks on Apple M5 Max MacBook Pro (`128 GiB`) compare `inky` against vanilla `llama-server` (`-fa auto`, both default FP16 and `-ctk q8_0 -ctv q8_0`) across `1, 2, 4, 8, 16, 32, 64` concurrent lanes (`README.md`, `docs/PERFORMANCE.md`, `docs/assets/readme-lanes-speed.svg`, `docs/assets/perf-vs-llama-lanes.svg`): `inky --kv8` scales from `75.6 tok/s` at `1` lane (`1.59x` vs. `llama-server` FP16's `47.43 tok/s`) to **`430.8 tok/s` at `64` lanes in `43.63 GiB` Metal GPU memory** (**`2.75x`** faster and **`34.17 GiB` less GPU memory** than `llama-server` FP16's `156.68 tok/s` / `77.80 GiB` `MTL0`, and **`2.26x`** faster than `llama-server` `Q8_0`'s `190.26 tok/s` / `51.73 GiB` `MTL0`), while exact `inky` FP16 reaches **`348.5 tok/s` (`2.22x`)** in `68.71 GiB`.
- `docs/QUALITY-REPLAY.md` records deterministic Apple M5 Max (`128 GiB`, `temperature=0`, `seed=42`) `FP16` vs. `--kv8` evaluations: `--kv8` scores **`9/9` (`100.0%`, `19.08 s` avg wall)** vs. `FP16`'s `8/9` (`88.9%`) on `tools/quality` and matches `FP16` **`3/5` vs. `3/5` (`100.0%` check parity, `4/5` byte-identical outputs)** across `21.1K–23.9K`-token long-context Go bugfix and 64-bit hex needle retrieval torture cards (`7K–20K` tokens outside the 1,024-token sliding window, graded with `go test -race`).
- `docs/LANE-SWEEP.md` and `docs/ROADMAP.md` (`t-audit-replay-capacity-rerun`, `t-au-replay-real`) record the single-tenant Apple M5 Max (`128 GiB`) replay of **`1,242` authorized production coding-agent turns across `1,239` cards** (`20,910.5` median / `22,648.7` mean prompt tokens, `90.5%` `tool_calls`) against `inky serve --kv8 -c 65536 -n 4096 --lanes 96 --queue 128 --effort low` (`600.18 MiB` worst-case 64K KV reserve/lane, admitting all `96` lanes inside macOS's default `107.52 GiB` working set), establishing the **`64`-lane autonomous batch throughput knee (`2,392.8 cards/hr`, `0` errors, `0` `429`s, `87.80 GiB` peak footprint, `8.86 GiB` minimum OS headroom)** alongside the cold simultaneous-burst `PickKnee` physical bound (`<= 4` uncached lanes for `< 20 s` `p95` TTFT on `10K–21K` prompts).
