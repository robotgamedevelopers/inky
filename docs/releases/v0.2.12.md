Inky 0.2.12 wires opt-in DSpark speculative decoding into `inky serve`, adds independent RSS, process footprint, and streamed-only TTFT replay telemetry, enforces workflow main-branch non-cancellation and branch hygiene checks, and updates pinned GitHub Actions. These changes build on 0.2.11.

- `inky serve --dspark <mtp.gguf> --draft-k <1..=4>` (`src/dspark.rs`, `src/scheduler/verify.rs`, `src/engine.rs`, `src/kernels.metal`, `src/serve.rs`, and `src/serve/block_cache.rs`, default off) loads mainline `dflash` (neural and `suffix` modes) and `inkserve.mtp` GGUF drafters, enforces `spans * (1 + k) <= 128` (`check_verify_capacity` / `select_verify_or_decode_fallback`) with fallback to 1-token decode, verifies batches on GPU via `k_dspark_reject` (greedy and exact stochastic rejection sampling) or CPU `Sampler::verify_round` (`top_k`/`top_p`), rolls back rejected drafts across Layer 3 paged `Full`/`Window`/`cs` state, and exposes `dspark_*` counters on `/health` (`tests/dspark_serve_m5.rs`).
- `tools/replay` (`memory.go`, `replay.go`, `knee.go`, and `docs/LANE-SWEEP.md`) adds `--force-stream`, `/health` `process_footprint_bytes`, OS `ps` `peak_rss_bytes` (`--server-pid`), and independent `vm_stat`/`sysctl` `min_headroom_bytes` (`--measure-headroom`), keeping the scripted `tests/replay/recorded_cards.jsonl` fixture explicitly distinct from real fleet card captures.
- `scripts/release_ci.py` (`validate_no_main_cancellation`), `scripts/check_branch_hygiene.py`, `tests/test_release_ci.py`, and `tests/test_branch_hygiene.py` verify that no workflow cancels non-PR runs on `main`, tags, or schedules and audit branch/PR hygiene (`t-au-s-branches`), alongside Dependabot SHA updates for `actions/checkout` (`v7.0.1`), `actions/cache` (`v6.1.0`), `actions/setup-java` (`v6.3.0`), and `actions/setup-go` (`v7.1.0`).
