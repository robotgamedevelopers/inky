### `serve --kv8`, `kvb`-validated `SpillStore` v2 headers, host/GPU overlap, and cache/admission hardening

- **`serve --kv8` & `kvb`-tagged `SpillStore` v2 headers (`src/main.rs`, `src/serve.rs`, `src/spill.rs`, `docs/README.md`).** Wires `--kv8` (`1`-byte Q8_0 K/V blocks) into `inky serve` (exposing `"kv8": true|false` on `/health`), upgrades `SpillStore` (`open_with_kvb`) to schema v2 headers carrying and validating explicit `kvb` (`1` vs `2`) before payload SHA-256 restore so switching `--kv8` on an existing `--spill-dir` cleanly rejects width-mismatched blocks instead of misreading strides.
- **Host/GPU step overlap (`src/serve.rs`, `src/serve/block_cache.rs`).** While a committed Metal `MTLCommandBuffer` executes on GPU, `overlap_host_work_during_gpu` drains newly arrived jobs from the channel, drops disconnected queued jobs, transitions disconnected in-flight GPU lanes via `CancelInStep` (`InStep -> Cancelling`) while keeping all `BlockPool`/`BlockTable` pins held until `wait_committed_step` + `planner.complete_step()` finish, defers release of disconnected waiting lanes until step completion, and runs bounded disk-only `maintain_spill_during_gpu` without touching active RAM pools.
- **Crash-safe `SpillStore` ownership, bounded SSD restore, and physical KV admission (`#78`, `#79`, `src/spill.rs`, `src/prefix.rs`, `src/serve/block_cache.rs`, `src/serve.rs`).** Locks `--spill-dir` against concurrent writers, skips surviving disk IDs on fresh allocation, bounds prefix-tree storage by peak occupancy, refreshes missing sliding-window blocks on SSD restore with bounded scratch, charges newly pinned `Full`/`Window` blocks and singleflight suffix reservations at admission, and enforces physical KV pool row limits before opening HTTP streams while sizing prefill spans to the `Window` pool.

### Cross-lane sliding-window scratch-tail isolation, `GroupedLayout` fairness witness, and `prep_ms` timing

- **Per-span sliding-window scratch tail zeroing (`#59`, `src/engine.rs`, `src/prefill.metal`, `specs/ScratchTail.tla`).** `k_attn_h` reads keys in whole 64-position (`ATT_AK`) tiles, so a prefill span's final tile reads masked scratch rows past `p0 + t` up to the next multiple of 64. Because `0 * NaN = NaN`, an earlier span in the same multi-span step (or a longer span in the prior layer) could leave non-finite keys in those rows and leak across lanes. Multi-span sliding-window prefill now zeroes `[p0 + t, next_multiple_of(64))` in scratch via `k_kvcopy` (`to_ring = 2`) before attention, verified by the `ScratchTail` TLA+ model (`ScratchTail3`, `ScratchTail4`, `ScratchTailOneSpan`, and reversed witness `ScratchTailNoZero`).
- **Cross-lane leak assertion in sabotaged `inky poolgate` (`#59`, `src/poolgate.rs`, `src/main.rs`, `tests/ci.sh`).** `Report::sabotaged` tracks the exact sabotaged lane index, `Layer3Pool` withholds sabotaged-lane blocks from `PrefixTree` deduplication, and `poolgate::leaked` + `tests/ci.sh` require that `INK_POOLGATE_SABOTAGE=1` triggers `POOL GATE DIFFERS` with exit code `1` while proving zero other lanes differ.
- **`GroupedLayout` fairness witness and `prep_ms` timing (`#53`, `specs/GroupedLayout.tla`, `specs/AdvanceUnfair.cfg`, `specs/RestageOutputs.cfg`, `src/serve/timing.rs`, `src/serve/scheduler_trace.rs`).** Adds `AdvanceUnfair` and promotes `RestageOutputs` into CI; separates post-admission lane preparation (`prep_ms`) from `queue_ms` and `prefill_ms`; and updates the scheduler trace driver to schema v2 (`refuse_ctx`, `admit` source/`from`, immediate lost-terminal-event assertion).

## Getting started

With Rust installed, `cargo install inky-engine` builds and installs `inky` from crates.io instead.

The model is LM Studio's `Inkling-2-Mini-Q4_K_M.gguf` (or a `native-q8rest-o6` GGUF converted with `tools/inkconvert`), read by default from `~/.lmstudio/models/lmstudio-community/Inkling-2-Mini-GGUF/`; `-m` points at another path.

```sh
gh release download v0.2.3 -R robotgamedevelopers/inky
shasum -a 256 -c SHA256SUMS
mv inky_v0.2.3_darwin_arm64 inky && chmod +x inky
./inky chat
```

To serve over loopback or a private network:

```sh
sudo ./inky tune-memory                                         # once, optional: installs inky mode
./inky serve --lanes 32 -c 131072 -n 16384                      # standard decoding
./inky serve --lanes 32 -c 131072 -n 16384 --loopcd 0.3         # with Adaptive LoopCD-Logits
./inky serve --lanes 32 -c 131072 -n 16384 --kv8 --loopcd 0.3   # 8-bit KV cache + LoopCD
```

[docs/README.md](https://github.com/robotgamedevelopers/inky/blob/v0.2.3/docs/README.md) and [docs/FLEET-SPRINT.md](https://github.com/robotgamedevelopers/inky/blob/v0.2.3/docs/FLEET-SPRINT.md) cover every command, serve flag, and fleet provider recipe.
