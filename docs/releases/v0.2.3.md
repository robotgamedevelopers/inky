Correctness, formal verification, and CI velocity release of inky fixing a cross-lane sliding-window scratch-tail NaN leak in multi-span Layer 2 prefill, tightening sabotaged `poolgate` to assert zero cross-lane leakage across Layer 3, adding the `GroupedLayout` fairness witness and `prep_ms` lane-preparation timing phase, and parallelizing pull-request CI to complete in about a minute with full nightly coverage and automated TLA+ tier accounting.

## What changed

### Cross-lane sliding-window scratch-tail isolation & `poolgate` leak detection

- **Per-span sliding-window scratch tail zeroing (`src/engine.rs`, `src/prefill.metal`, `specs/ScratchTail.tla`).** `k_attn_h` reads keys in whole 64-position (`ATT_AK`) tiles, so a prefill span's final tile reads masked scratch rows past `p0 + t` up to the next multiple of 64. Because `0 * NaN = NaN`, an earlier span in the same multi-span step (or a longer span in the prior layer) could leave non-finite keys in those rows and leak across lanes. Multi-span sliding-window prefill now zeroes `[p0 + t, next_multiple_of(64))` in the scratch via `k_kvcopy` (`to_ring = 2`) before attention, verified by the new `ScratchTail` TLA+ model (`ScratchTail3`, `ScratchTail4`, `ScratchTailOneSpan`, and reversed witness `ScratchTailNoZero`).
- **Cross-lane leak assertion in sabotaged `inky poolgate` (`src/poolgate.rs`, `src/main.rs`, `tests/ci.sh`).** `Report::sabotaged` now tracks the exact sabotaged lane index, `Layer3Pool` withholds sabotaged-lane blocks from `PrefixTree` deduplication, and `poolgate::leaked` + `tests/ci.sh` require that `INK_POOLGATE_SABOTAGE=1` triggers `POOL GATE DIFFERS` with exit code `1` while proving zero other lanes differ.

### Formal fairness witness, scheduler trace hardening, and `prep_ms` timing

- **`GroupedLayout` fairness witness and output negative control (`specs/GroupedLayout.tla`, `specs/AdvanceUnfair.cfg`, `specs/RestageOutputs.cfg`, `specs/run_tlc.zsh`).** Adds `AdvanceUnfair` (weak fairness narrowed to staging while keeping deadlock checking enabled so TLC witnesses stuttering with `Advance` enabled) and promotes `RestageOutputs` (the redundant-load mutant checked against `VisitedKeys` and `OrderedPartials` alone) into CI.
- **Lane preparation phase (`prep_ms`) & scheduler trace schema v2 (`src/serve.rs`, `src/serve/timing.rs`, `src/serve/backend.rs`, `src/serve/scheduler_trace.rs`, `docs/README.md`, `specs/README.md`).** Separates post-admission lane preparation (`prep_ms`) from `queue_ms` and `prefill_ms`, adds the `lane_preparation_is_its_own_phase` unit test, and updates the scheduler trace driver to schema version 2 (`refuse_ctx`, `admit` source/`from`, and immediate assertion on lost terminal events instead of hanging).

### One-minute parallel pull-request CI & automated TLA+ tier accounting

- **Parallel PR CI & `nightly.yml` split (`.github/workflows/ci.yml`, `.github/workflows/nightly.yml`, `Cargo.toml`, `tests/ci.sh`, `tests/serve.sh`).** Splits PR CI into parallel `unit`, `go`, `tla` (`memmode`, `blocks`, `grouped`, `traces`), `m5-gpu` (`tests/ci.sh pr`), and `m5-serve` (`INKY_SERVE_PROBES_ONLY=1`) jobs using an incremental `[profile.ci]` build, while moving the exhaustive `CacheScheduler` and `layout-nightly` TLA+ runs, clean `--release` CPU build/tests, full M5 GPU gates (`tests/ci.sh full`, `tests/nightly.sh`), and serve API negative control to `.github/workflows/nightly.yml`.
- **Parallel TLA+ runners & tier-coverage self-test (`scripts/check-tla.sh`, `scripts/check-tla-tiers.sh`, `scripts/check-memmode-traces.sh`, `specs/run_tlc.zsh`, `specs/run_cache_scheduler.sh`).** Runs `specs/run_tlc.zsh`, `memmode`, and all four trace-conformance checkers (`memmode`, `blockbook`, `cache`, `scheduler`) in parallel, caches the SHA-256-verified `tla2tools.jar`, and enforces via `scripts/check-tla-tiers.sh` (plus `--self-test`) that every `.cfg`, trace script, and mutation runs in exactly one CI tier.

## Getting started

With Rust installed, `cargo install inky-engine` builds and installs `inky` from crates.io instead.

The model is LM Studio's `Inkling-2-Mini-Q4_K_M.gguf` (or a `native-q8rest-o6` GGUF converted with `tools/inkconvert`), read by default from `~/.lmstudio/models/lmstudio-community/Inkling-2-Mini-GGUF/`; `-m` points at another path.

```sh
gh release download v0.2.3 -R robotgamedevelopers/inky
shasum -a 256 -c SHA256SUMS
mv inky_v0.2.3_darwin_arm64 inky && chmod +x inky
./inky chat
```

To serve over loopback or a private network:

```sh
sudo ./inky tune-memory                                # once, optional: installs inky mode
./inky serve --lanes 32 -c 131072 -n 16384             # standard decoding
./inky serve --lanes 32 -c 131072 -n 16384 --loopcd 0.3 # with Adaptive LoopCD-Logits
```

[docs/README.md](https://github.com/robotgamedevelopers/inky/blob/v0.2.3/docs/README.md) and [docs/FLEET-SPRINT.md](https://github.com/robotgamedevelopers/inky/blob/v0.2.3/docs/FLEET-SPRINT.md) cover every command, serve flag, and fleet provider recipe.
