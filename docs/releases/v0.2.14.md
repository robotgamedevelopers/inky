Inky 0.2.14 adds opt-in far-key pruning on full-attention passes (`--full-attn-budget`), sub-4-bit weight quantizations (`Q3_K`, `Q2_K`, and compact `Q3_0` for `ffn_down_exps`), and the `tools/bestofn` best-of-N parallel Chat Completions check runner. These changes build on 0.2.13.

- **Full-attention far-key pruning (`t-later-prune`)**: Adds opt-in `--full-attn-budget <tokens>` (`>= 128`; default `None` remains 100% unpruned and bit-identical) across `src/main.rs`, `src/serve.rs`, `src/engine.rs` (`FULL_ATTN_SINK = 64`, `full_attn_decode_plan`, `build_full_decode_groups`), `src/kernels.metal` (`DecodeSpanDesc::full_recent_start`, `k_attn_dec_solo`, `k_attn_grp_dec`), and `src/prefill.metal` (`k_attn_h`, `k_attn_h_blk`, `k_attn_bt`, `k_attn_bt_blk`, `k_attn_b`, `k_attn_b_blk`), retaining 64 sink tokens plus `(budget - 64)` recent keys across prefill and Layer 2/3 decode passes.
- **Sub-4-bit weight quantizations (`t-later-quant`)**: Adds native GGML `Q3_K` (`T_Q3_K = 11`, `3.4375 bpw`), `Q2_K` (`T_Q2_K = 10`, `2.625 bpw`), and compact `Q3_0` (`T_Q3_0 = 202`, `3.50 bpw` for `K % 32 == 0` tensors such as `ffn_down_exps`) across `tools/inkconvert` (`quant.go`, `quant_test.go`, `gguf.go`, `main.go`), `src/gguf.rs`, `src/engine/model.rs`, `src/kernels.metal` (`dot_q3k`, `dot_q2k`, `dot_q3_0`, `down_rows`), and `src/prefill.metal` (`deq16`).
- **Best-of-N parallel check runner (`t-later-best-of-n`, `:doing`)**: Adds the stdlib-only Go package and CLI `tools/bestofn` (wired into `.github/workflows/ci.yml` `go` job with `go vet` and `go test -race -count=1 ./...`) that dispatches `N` parallel `/v1/chat/completions` attempts sharing one prompt prefix with distinct seeds, executes deterministic checks in isolated temp directories, cancels remaining lanes immediately on first pass, and reports `pass@1` vs `best-of-N`, prefix-cache reuse, and wall-clock time.
