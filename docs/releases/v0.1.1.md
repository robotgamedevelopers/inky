Point release of inky with serving and cache correctness fixes, model and runtime hardening, and native release-precision weight support.

## What changed

### Serving and cache correctness

- **Sliding-window cache invalidation.** A lane's retained prompt prefix is invalidated once decode writes wrap into its 1,024-position sliding-window ring, preventing stale reply K/V entries from being reused on later turns.
- **Request lifecycle and cancellation.** Request header reads enforce a cumulative deadline; admission permits and cancellation flags travel with each job so disconnected clients are dropped before lane assignment or prefill; streaming responses poll peer disconnect during silent thinking and tool-JSON spans; bounded per-job channels and socket write timeouts apply clean backpressure.
- **Streaming, budgets, CLI, and `/health`.** Streaming UTF-8 decoding replaces invalid leading bytes with `\u{FFFD}` and flushes trailing sequences cleanly; `/v1/messages` clamps positive `max_tokens` budgets against the remaining prompt context window and returns Anthropic-style errors for over-context prompts; `/v1/chat/completions` rejects invalid token budgets with HTTP 400; CLI flag parsing, empty API key checks, and non-loopback `--bind` authentication guards are enforced strictly; `GET /health` reports `active_lanes` and `inflight` counts.

### Model, `memd`, and numerical safety

- **Checked GGUF loading and Metal lifetime.** GGUF metadata, quantization block divisibility, tensor offsets, and vocabulary row dimensions are validated with checked arithmetic before buffer creation; `Engine` field ordering releases Metal buffers before unmapping the model file; Metal command buffer completion status is checked on both prefill and decode steps.
- **`inky memd` hardening.** The root helper keeps its socket parent directory root-owned, verifies peer UID and socket permissions, checks every syscall return value, tags saved wired-memory limits with `kern.boottime`, distinguishes missing from unreadable recovery state, and verifies `launchctl` teardown during uninstall.
- **Numerics and tokenization.** Reference logit checks reject non-finite logits or KL values and validate reference token bounds; speculative verification accepts explicit `draft_tokens`, rejects non-finite logits cleanly, and guards tiny positive temperatures against overflow; BPE merging uses ranked heap/list updates rather than quadratic rescans while preserving identical token IDs.

### Native release-precision weights and inference features

Adopted from [chadlyb/erisinky](https://github.com/chadlyb/erisinky) (attributed to Chad, `chadlyb`):

- **Native `native-q8rest-o6` weights and `tools/inkconvert`.** Metal prefill, decode, and single-stream kernels support native `NV4` (`T_NV4=200` + `.gscale`) and `MX8` (`T_MX8=201`) experts alongside `Q8_0` attention/embeddings and `Q6_K` output weights, paired with the standalone Go `tools/inkconvert` converter.
- **Thinking-token budget.** `--thinking-budget` (and per-request `thinking_budget` / `thinking.budget_tokens`) softly closes `<|content_thinking|>` at the configured token limit and masks further thinking tokens so responses finish within budget.
- **Sampling and chat templates.** Added GPU Gumbel-max sampling (`k_gumbel`) for full-vocabulary draws, CPU `atanh` raw-logit pre-filtering for top-k/top-p sampling, and 11 `transformers`-verified chat template golden tests.

## Getting started

With Rust installed, `cargo install inky-engine` builds and installs `inky` from crates.io instead.

The model is LM Studio's `Inkling-2-Mini-Q4_K_M.gguf` (or a `native-q8rest-o6` GGUF converted with `tools/inkconvert`), read by default from `~/.lmstudio/models/lmstudio-community/Inkling-2-Mini-GGUF/`; `-m` points at another path.

```sh
gh release download v0.1.1 -R robotgamedevelopers/inky
shasum -a 256 -c SHA256SUMS
mv inky_v0.1.1_darwin_arm64 inky && chmod +x inky
./inky chat
```

To serve:

```sh
sudo ./inky tune-memory              # once, optional: installs inky mode
./inky serve --lanes 16 -c 131072    # on 127.0.0.1:8090
```

[docs/README.md](https://github.com/robotgamedevelopers/inky/blob/v0.1.1/docs/README.md) covers every command, the serve flags and how to use inky as a provider.
