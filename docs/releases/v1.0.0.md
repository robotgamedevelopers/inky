Inky `v1.0.0` marks the production 1.0 release of `inky-engine` (`GPL-3.0-or-later`), a hand-fused Metal 4 (`MTL4` tensor-core) inference engine and multi-lane HTTP server for Thinking Machines' **Inkling 2 Mini** (`35.9B` total / `2.9B` active hybrid sliding-window attention, full-attention, and ShortConv MoE) on Apple Silicon Macs.

## Performance (Apple M5 Max, `128 GiB`)

Measured single-tenant against vanilla `llama-server` (`-fa auto`) on `Inkling-2-Mini-Q4_K_M.gguf` (`docs/PERFORMANCE.md`, `docs/LANE-SWEEP.md`, `docs/QUALITY-REPLAY.md`):

- **Single-lane decode & prefill**: **`75.6 tok/s`** at matched `20K` (`~20,480`-token) working context with `--kv8` (**`1.59x`** `llama-server` FP16's `47.43 tok/s`; `73.4 tok/s` live / `79.4 tok/s` `inky bench` in exact FP16), **`95.3–106 tok/s`** short-context decode (**`2.33x–2.59x`** `llama-server`'s `41 tok/s`), and **`4,186–4,531 tok/s`** prompt prefill (`2.4K–2.7K` prompts).
- **`64`-lane `20K` scaling**: **`430.8 tok/s`** across `64` concurrent `20K` lanes with `--kv8` in **`43.63 GiB`** Metal GPU memory — **`2.75x` faster** and **`34.17 GiB` less GPU memory** than `llama-server` FP16 (`156.68 tok/s`, `77.80 GiB` `MTL0`), and **`2.26x` faster** than `llama-server` `Q8_0` (`190.26 tok/s`, `51.73 GiB` `MTL0`). Exact FP16 reaches **`348.5 tok/s` (`2.22x`)** in `68.71 GiB`. Across other contexts, `64` lanes reach **`529.7–578 tok/s`** at `2K` (`541.5 tok/s` `--kv8`) and **`322 tok/s`** at `42K`.
- **Production fleet replay & `--kv8` quality parity**: **`2,392.8 cards/hr`** at the `64`-lane `64K`-context knee across **`1,242`** replayed production coding-agent turns (`1,239` cards, `0` errors, `0` `429`s, `87.80 GiB` peak footprint, `8.86 GiB` minimum OS headroom). In deterministic evaluations (`temperature=0`, `seed=42`), `--kv8` scores **`9/9` (`100%`)** vs. FP16's `8/9` (`88.9%`) on `tools/quality` and matches FP16 **`3/5` vs. `3/5`** (`100%` check parity, `4/5` byte-identical outputs) on `21.1K–23.9K`-token long-context retrieval and `go test -race` cards.

## Engine & Serving Stack

- **Unified cache-fixed-split attention**: `64`-token sliding-window splits and `256`-token full-attention splits drive contiguous, Layer 3 paged, and disk-backed (`--kv-disk`) prefill and decode with identical arithmetic (`inky crosspath` bit-identical across all `12/12` split boundaries `63..2049` and reproducible chip goldens across Apple M5 Pro and M5 Max), alongside `--no-mpp` Metal 3.2 fallback kernels.
- **Expert-grouped tensor-core MoE decode**: Routes `(token, expert_slot)` pairs by expert ID into coalesced `DEC_M=16`, `DEC_K=128` tiles (`k_moe_dec_sg4` / `k_moe_dec_sg8`), reading each touched expert once across all active lanes (`2.83x` wall / `3.63x` GPU speedup at `64` lanes with `0`-bit difference vs. ungrouped decode).
- **Layer 3 paged prefix sharing & SSD spill tier**: Append-only, reference-counted `64`-token `ServeBlockCache` blocks (`EntryTree` + `BlockPools`) with private unsealed decode tails and grouped shared-KV attention deliver **`6.82x` lower KV memory** (`1,008 MiB` vs. `6,878 MiB`) at `16 × 8K`, paired with starvation-bounded `ServeStepPlanner` scheduling, automatic Metal working-set admission, and SHA-256 verified `--spill-dir` SSD checkpoints hardened against mid-write `SIGKILL`.
- **Serving & inference modes**: OpenAI `POST /v1/chat/completions` and Anthropic `POST /v1/messages` (+ `/v1/messages/count_tokens`) streaming parity, byte-level RFC 8259 JSON-schema constrained tool-call sampling, `--kv8` (`INKY_KV8=1` default in `scripts/inky-fleet-serve.sh`; exact FP16 default on raw `inky` CLI), opt-in `--dspark` speculative decoding with GPU rejection sampling and Layer 3 rollback, opt-in `--full-attn-budget` far-key pruning, `LoopCD-Logits` (`--loopcd`), sub-4-bit weight quantizations (`Q3_K`, `Q2_K`, `Q3_0`), and `inky tune-memory` / `inky memd` wired-memory management.

## Verification Gates

- **Reference parity**: `inky check` enforces `llama.cpp` argmax agreement (`worst KL <= 0.01`) across `58/58` short-prompt decode, `24/24` post-`2,380`-token prefill, and `58/58` batched decode-step reference positions.
- **Formal models & runtime traces**: Bounded TLA+ safety, action-property, and liveness specifications (`BlockLayout`, `CacheScheduler`, `MemMode`, `PrefixTree`, and `ServeStepTrace` / `ServeCacheTrace` / `ServeOwnershipTrace`) checked with reversed negative mutant witnesses and runtime trace conformance in CI (`143` checks and mutants across PR and nightly tiers).
- **Fuzzing & performance envelopes**: `cargo-fuzz` GGUF and BPE tokenizer validation (`fuzz/fuzz_targets/gguf_load.rs`) and `inky perfgate` across `2K`, `20K`, and `42K` contexts (`1..=64` lanes) with planted mismatch sabotage checks.

## Getting Started

With Rust installed, `cargo install inky-engine` builds and installs `inky` from crates.io, or download the `darwin/arm64` release binary:

The model is LM Studio's `Inkling-2-Mini-Q4_K_M.gguf` (or a `native-q8rest-o6` GGUF converted with `tools/inkconvert`), read by default from `~/.lmstudio/models/lmstudio-community/Inkling-2-Mini-GGUF/`; `-m` points at another path.

```sh
gh release download v1.0.0 -R robotgamedevelopers/inky
shasum -a 256 -c SHA256SUMS
mv inky_v1.0.0_darwin_arm64 inky && chmod +x inky
./inky chat
```

To serve locally on loopback (or over a private network with `--bind <private-ip>:8096 --key-env INKY_SERVE_KEY`; `--kv8` is enabled by default in `scripts/inky-fleet-serve.sh`):

```sh
sudo ./inky tune-memory                    # once, optional: installs inky memd
./inky serve --lanes 64 -c 65536 --queue 128 --kv8
```

See [docs/README.md](https://github.com/robotgamedevelopers/inky/blob/v1.0.0/docs/README.md) and [docs/PERFORMANCE.md](https://github.com/robotgamedevelopers/inky/blob/v1.0.0/docs/PERFORMANCE.md) for the full command reference, serving flags, and hardware benchmarks.
